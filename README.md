# Cores & Números

Um aplicativo web interativo de apoio psicopedagógico desenhado para funcionar em conjunto com um baralho físico de cartas. O objetivo do jogo é promover a associação ágil de cores (Amarelo, Azul, Verde e Vermelho) e números (1 a 9).

## Como funciona
1. **Separe as cartas:** O utilizador espalha as cartas físicas do baralho na mesa.
2. **Escolha no App:** Através de uma interface limpa e intuitiva, o utilizador seleciona no aplicativo as mesmas cartas que estão na mesa.
3. **Sorteie e Procure:** O aplicativo sorteia aleatoriamente uma das cartas selecionadas. O jogador deve encontrar a carta correspondente na mesa o mais rápido possível!

## Tecnologias utilizadas
* **HTML5** e **JavaScript Vanilla**: Estrutura e lógica do jogo (incluindo armazenamento local via `localStorage`).
* **Tailwind CSS**: Estilização responsiva, moderna e focada em dispositivos móveis.
* **Google Fonts**: Tipografia *Quicksand* para uma leitura amigável e acessível.
* **Material Symbols**: Ícones visuais consistentes.
